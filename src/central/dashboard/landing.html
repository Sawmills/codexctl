01

Install codexctl

Pick your platform. Run it in your terminal.

macOS / Homebrew

brew install sawmills/tap/codexctl
Linux / arm64 & x86_64

Pinned to v0.1.34. Downloads the matching release and verifies its SHA-256 checksum before installation.

Requires curl, tar and sha256sum 
(
  set -eu
  case "$(uname -m)" in
    aarch64|arm64) arch=arm64 ;;
    x86_64) arch=x86_64 ;;
    *) echo "Unsupported architecture" >&2; exit 1 ;;
  esac
  version=v0.1.34
  archive="codexctl_${version}_Linux_${arch}.tar.gz"
  base="https://github.com/Sawmills/codexctl/releases/download/${version}"
  work=$(mktemp -d)
  trap 'rm -rf "$work"' EXIT
  cd "$work"
  curl -fLO "$base/$archive"
  curl -fLO "$base/$archive.sha256"
  sha256sum --check "$archive.sha256"
  tar -xzf "$archive"
  mkdir -p "$HOME/.local/bin"
  install -m 755 codexctl "$HOME/.local/bin/codexctl"
)
export PATH="$HOME/.local/bin:$PATH"
codexctl --version

Add $HOME/.local/bin to your shell’s PATH to keep the command available in new terminals.
