Two commands, then one approval

  1. Install codexctl

    macOSHomebrew

    brew install sawmills/tap/codexctl
    Linuxarm64 and x86_64

    Pinned to v. The script checks the SHA-256 checksum before it installs. Requires curl, tar, and sha256sum. 

    (
  set -eu
  case "$(uname -m)" in
    aarch64|arm64) arch=arm64 ;;
    x86_64) arch=x86_64 ;;
    *) echo "Unsupported architecture" >&2; exit 1 ;;
  esac
  version=v
  archive="codexctl_${version}_Linux_${arch}.tar.gz"
  base="https://github.com/Sawmills/codexctl/releases/download/${version}"
  work=$(mktemp -d)
  trap 'rm -rf "$work"' EXIT
  cd "$work"
  curl -fLO "$base/$archive"
  curl -fLO "$base/$archive.sha256"
  sha256sum --check "$archive.sha256"
  tar -xzf "$archive"
  mkdir -p "$HOME/.local/bin"
  install -m 755 codexctl "$HOME/.local/bin/codexctl"
)
export PATH="$HOME/.local/bin:$PATH"
codexctl --version

    Add $HOME/.local/bin to your shell’s PATH so new terminals find the command.

  2. Connect it to this account server

    codexctl connect \
  --server  \
  --name "<machine>"

    Replace <machine> with a name you will recognize, such as “Studio MacBook”.

  3. Approve it in your browser

    The connect command opens a page. Sign in with company SSO, check that the code matches your terminal, then approve.

    No browser on that machine? Add --no-browser and open the printed link on another computer.
