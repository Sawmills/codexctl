# Triage labels

Use the default mapping between each skill role and its Linear label:

- `needs-triage`: a maintainer must evaluate the issue.
- `needs-info`: the issue needs more information from the reporter.
- `ready-for-agent`: the issue is specified and ready for an unattended agent.
- `ready-for-human`: the issue needs human implementation.
- `wontfix`: the team will not act on the issue.

Use these names when a Matt skill refers to a triage role. Preserve unrelated labels.
Check existing Linear labels before applying or creating labels; do not create duplicates.
