# v0.1.58

- Automatic account-server launches recognize Codex's native terminal usage-limit
  error and resume the same session on another included account. Explicit
  `--account` launches remain pinned, and recovery still excludes usage-based
  accounts (SAW-12574, #242).
- Quoted tool output does not trigger usage-limit recovery. Error detection keeps
  UTF-8 intact across output reads and preserves the context of long JSON records.
- Managed Codex launches count terminal HTTP capacity stops once after native
  retries, including explicit account pins. Recovered requests do not count as
  stops, and native retry behavior stays unchanged (SAW-13482, #243). Plain Codex
  coverage remains a separate follow-up.
- Missing native completion evidence emits a warning and increments
  `codexctl_relay_capacity_confirm_unavailable_total`; it does not change the
  launch result or infer a capacity stop.

Rollout: upgrade and restart relays on v0.1.58 before new managed launches.
Existing launches gain the fixes at their next planned restart. Installing this
release does not restart a lane or relay. HQ owns the Mac upgrades and relay
restart.
