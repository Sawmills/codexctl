# v0.1.55

- Release symbols: publish matching Darwin dSYM archives and UUID records, plus Linux split debug archives, for both binaries on all four supported platforms. Each asset has a SHA-256 checksum. The existing packager checks Darwin UUID agreement before stripping debug sections and links Linux binaries to their debug files (SAW-13349, A236).
- Reset listing: show expected routing-unknown accounts in dim text with a partial total and retry note. `codexctl resets` succeeds when those are the only gaps; genuine read errors still fail, and listing never redeems a reset (SAW-13370, #235).
- Account server metrics: accept `/metrics` scrapes without a bearer. Account and machine endpoints keep their authentication. Server activation requires a separate operator GO and a check of network exposure; the legacy scrape credential and launch option remain for the staged cleanup (SAW-13160, #234).

Rollout: HQ upgrades the Macs and restarts their relays after the guide notice, then checks live CPU. Installing this release does not deploy the account server or enable routes, billing, or reset redemption.
