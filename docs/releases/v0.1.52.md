# v0.1.52

- Relay: prove the exact loopback listener with a per-listener private HMAC key before status, enable, activation, or pinned launch. Route state is rechecked under the relay lock, unsafe identity state fails closed, and direct disable remains available for rollback (SAW-12569, #200).
- Relay: keep the proof bounded to the control plane. It does not authenticate later bearer connections or proof-forwarding proxies.

Rollout: upgraded clients refuse an old relay. Restart each relay on the new binary before starting new managed launches. On macOS, upgrade the binary and restart `ai.sawmills.codexctl-relay` before routing. This release does not restart hosts or enable relay routes.

This release does not deploy the account server or change account, model, billing, reset, or workflow behavior.
