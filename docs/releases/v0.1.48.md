# v0.1.48

- Relay: observe streamed failures after output starts without changing forwarded bytes. Add bounded `stream_failure` logs and `codexctl_relay_stream_failures_total`; provider messages and unknown error keys never enter logs (#170, SAW-12569). See [the relay guide](../relay.md).
- Relay: report capacity outcomes to central metrics through a bounded queue. Export exhaustion event times so alerts detect a single event before the first scrape (#161, SAW-12573).
- Server: recover shared login crashes and takeovers (#154, SAW-12484), and serve valid cached tokens across replicas with the opt-in token fast path (#162).
- Server: record the bounded provider reason when an owner refresh is rejected (#163, SAW-12651).

This release does not deploy the central server or change lane settings. Install the relay on one host and restart its unit separately.
