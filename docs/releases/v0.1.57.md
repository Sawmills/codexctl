# v0.1.57

- HerdR detects Codex when `codexctl codex resume <id>` runs without `--account` on
  a private PTY. The Unix wrapper re-execs once with the supported `HERDR_AGENT=codex`
  hint before account selection. Its PID, arguments, working directory and exit status
  are preserved; native session identity and resume reporting stay intact (SAW-13475).

Existing launches need their next planned restart to gain the hint. Installing this
release does not restart a lane or relay. HQ owns the Mac upgrades and relay restart.
