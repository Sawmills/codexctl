# v0.1.53

- Relay: fix the v0.1.52 startup refusal on hosts whose older relay created `~/.codexctl/relay/` with mode `0755`. The shared parent may retain that mode when owned by the current user and not writable by group or others; no manual permission change is needed (SAW-12569, #202).
- Keep the store root and `identity/` directory private (`0700`), keys private (`0600`), and no-follow/owner checks intact. Shared permissions and evidence files remain unchanged.

Rollout: restart the relay on the new binary before new managed launches. Upgraded clients require its point-in-time identity proof. HQ handles the Mac upgrade and relay restart after the guide notice; installing this release does not enable routes or restart services.
