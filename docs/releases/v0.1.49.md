# v0.1.49

- Client: stop forcing an OAuth refresh on every 60-second `central-token` poll. Request a refresh when the last access token has less than one hour left, or the same parent process calls the same connection within 10 seconds (#178, SAW-12766).
- Client: keep expiry and its revision in a private sidecar so released helpers can still read connection files after rollback. Replace malformed or unreadable call history without blocking token delivery (#178).
- Server: recover retryable fenced owners from committed credentials, and serve recent tokens under a 60-second forced-refresh guard. Add bounded forced-refresh logs and metrics (#176, SAW-12766).

The guide owns client rollout. Server deployment requires separate HQ authorization. See [the central server guide](../central-server.md).
